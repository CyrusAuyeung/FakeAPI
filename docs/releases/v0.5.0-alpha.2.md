# FakeAPI v0.5.0-alpha.2

本次预览完善思考模式的连续聊天，并加入六个平台的混合初始化模板。

- Chat 的非空 assistant `reasoning_content` 可重传；普通 Responses summary 和 Gemini thought 注解可继续聊天。
- 四协议思考开关/强度统一校验和映射，隐藏显示保持生成设置，不支持的控制在调用前拒绝。
- `init --template deepseek|gpt|claude|gemini|glm|kimi` 自动填入端点、模型、规则与能力，只需设置上游 Key。
- Claude 使用原生 Messages 上游，支持 Anthropic 入站的原始签名/脱敏思考块回传；签名块完整后输出，正文增量发送。
- 保留四个内置形象、素材导入、Key 管理和四字段隐私日志。

下载对应平台归档，解压后按 README 初始化、创建 FakeAPI Key 并启动。
[平台配置与思考设置](https://github.com/CyrusAuyeung/FakeAPI/blob/v0.5.0-alpha.2/docs/providers.md) 列出默认模型、控制字段、区域地址与兼容边界。

容器镜像：`ghcr.io/cyrusauyeung/fakeapi:v0.5.0-alpha.2`，提供 linux/amd64 和 linux/arm64。
现有部署先备份 SQLite，再替换二进制或镜像；配置/数据库不会被初始化覆盖。
新增模板是可选的，不自动迁移现有 YAML。数据库 schema 保持兼容。

发布验收包括三系统 Go/运行/race、六套官方 SDK、升级恢复、五个平台发行包及容器。
六供应商参数使用官方文档与本地契约测试；DeepSeek 另有真实上游联调记录。
其他供应商尚未完成账户真实调用；跨供应商签名、加密 Responses 和完整 Agent 循环仍不支持。
