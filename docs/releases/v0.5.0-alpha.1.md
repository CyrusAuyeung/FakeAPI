# FakeAPI v0.5.0-alpha.1

首个开发预览版，可下载二进制自行部署，无需安装 Go、Python、Node 或 Cherry Studio。

## 功能

- OpenAI Chat Completions、无状态 Responses、Anthropic Messages、Gemini v1beta 的文本核心与 SSE。
- 最新语义用户消息匹配；可配置规则、节奏、模拟思考、文案和素材导入。
- 恰好四份内置字符画：挥手、站立、捧腹大笑、思考。
- 选择性 OpenAI Chat 兼容上游；只把配置命中的请求交给 AI，保留受支持历史。
- SQLite 持久化 Key、到期、总/AI 次数、RPM、并发、在线修改及撤销。
- 日志只有时间、模型、耗时和命中规则；一致数据库备份和 CLI 管理。
- 明确 UTF-8 JSON 响应编码，支持 Windows PowerShell 5.1 直接读取中文回复。

## 下载和启动

选择系统与架构对应的归档，使用 SHA256SUMS 校验后解压。
Windows amd64、Linux amd64/arm64、macOS amd64/arm64 各有一份。

Windows：

```powershell
.\fakeapi.exe init --template preset --dir .\runtime
.\fakeapi.exe keys create --config .\runtime\fakeapi.yaml --policy demo --label local --expires-in 30d
.\fakeapi.exe serve --config .\runtime\fakeapi.yaml
```

保存显示的 Key；OpenAI 客户端基址填 `http://127.0.0.1:8787/v1`，
模型可选 `fakeapi-frog` 或 `fakeapi-test`。Linux/macOS 改用 `./fakeapi`。
完整 PowerShell 调用示例在随包 `docs/windows-quickstart.md`，无需额外客户端。

容器镜像：`ghcr.io/cyrusauyeung/fakeapi:v0.5.0-alpha.1`，包含 linux/amd64 和 linux/arm64。
配置初始化、只读配置挂载和持久数据卷按随包 README/compose 文档操作。

## 使用边界与恢复

本版本为预发行。有限 JSON Schema、单函数 fixture 和工具结果回传可用；
服务不执行工具。真实 AI 上游限定为 OpenAI Chat 兼容协议；其余协议是入站协议。
有状态 Responses、签名思考、音视频、多候选和完整 Agent 循环未纳入本版本。

数据库 schema 为 1。升级前用 `db backup` 备份，并保留旧二进制与配置。
同 schema 的新旧二进制切换已验收；未来 schema 会明确拒绝，恢复时使用匹配版本及备份。
恢复备份会回到备份时的额度，而不是保留之后的调用次数。
